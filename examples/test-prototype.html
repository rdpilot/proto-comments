Feedback on prototypes, without the screenshot dance.

One script tag. Your team clicks any element on a preview URL and leaves a pinned comment. You copy them as markdown into Claude Code. That's it.

Get started →

How it works

01

Drop the tag

Paste one line into your prototype's root layout. Env-gated so it never ships to production.

02

Invite reviewers

Enter their email. They get a magic link, click, land on the prototype already signed in.

03

Ship feedback to Claude

Click Copy markdown, paste into Claude Code. It walks the list element by element.
